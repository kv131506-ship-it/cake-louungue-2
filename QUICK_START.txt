  src/data/productsData.js

Add new products:
  - Add to products array in productsData.js
  - Product details page auto-generates the page for new IDs

Modify colors/styling:
  - src/pages/HomePage.css
  - src/components/ProductDetails/ProductDetails.css
  - src/components/MenuSection/MenuSection.css

Add new pages:
  1. Create src/pages/NewPage.jsx
  2. Add route in src/App.jsx
  3. Import and use in components

❓ TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════

Issue: "npm: command not found"
Fix: Install Node.js from https://nodejs.org/

Issue: Port 5173 already in use
Fix: Kill the process or use: npm run dev -- --port 3000

Issue: Module not found errors
Fix: Run: npm install (again)

Issue: Changes not showing
Fix: Clear browser cache (Ctrl+Shift+Delete) and refresh (F5)
